# Item Art Studio

AI eşya görsellerini oyun ikonuna çeviren (arka plan, 128×128, ortak palet), onaylatan ve toplu dışa aktaran yerel web aracı.

```bash
npm install
npm run dev     # http://localhost:5173
npm test
npm run build
```

Kullanım, çıktı biçimi ve kod yapısı: [`docs/araclar/item-art-studio.md`](../../docs/araclar/item-art-studio.md).
