# Item Art Studio

AI eşya görsellerini oyunun paletine çeken ve renk / malzeme varyantları üreten yerel web aracı.

```bash
npm install
npm run dev     # http://localhost:5173
npm test
npm run build
```

Kullanım, çıktı biçimi ve kod yapısı: [`docs/araclar/item-art-studio.md`](../../docs/araclar/item-art-studio.md).
