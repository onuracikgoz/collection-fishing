# Ajanlar

Planner, developer ve tester ajanlarını tmux'ta çalıştırır; dashboard hepsini izler ve prompt gönderir.

```bash
brew install tmux          # bir kez
./cg testbed setup         # bir kez: test klasörü
./cg agents up             # ajanlar + dashboard (http://127.0.0.1:7380)
```

Ayrıntı: [`docs/araclar/ajanlar.md`](../../docs/araclar/ajanlar.md).
