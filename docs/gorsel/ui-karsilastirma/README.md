# UI karşılaştırma

Her görsel: solda taslak (`docs/gorsel/ui-taslaklar/`), sağda Unity'nin çizdiği prefab (`Editor/UiShots.cs`, örnek veriyle, 1408x896, kit 2x).
Yeniden üretmek: Unity'de CollectionGame > UI > Capture Shots (`ui-shots/`), sonra aynı bölgeyi yan yana koy.

Bilinen fark: yazı tipi. Taslaktaki Türkçe harfli pixel font henüz yok, Unity'nin yerleşik fontu kullanılıyor. İkonlar (Google, Steam...) yer tutucu renkli kare.
